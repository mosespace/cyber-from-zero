# Study Plan

You can finish the course in **10 weeks** with about 30 minutes a day.

| Week | Module | Goal |
|------|--------|------|
| 1 | 1. Digital World | Explain how a web page reaches your screen |
| 2 | 2. Security Mindset | Explain the CIA triad to a friend |
| 3 | 3. Networking | Name five ports and what they do |
| 4 | 4. Operating Systems | Use ten Linux commands without looking |
| 5 | 5. Cryptography | Set up a password manager and MFA |
| 6 | 6. Threats | Spot a phishing email in under 10 seconds |
| 7 | 7. Web Security | Explain SQL injection and XSS and their fixes |
| 8 | 8. Defence | Design a simple layered defence for a small shop |
| 9 | 9. Ethical Hacking | Finish a beginner room on TryHackMe |
| 10 | 10. Response and Career | Write your 12-month plan |
