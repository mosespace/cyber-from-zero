Cybersecurity has more open jobs than skilled people. You can start with no degree if you build real skills.

## Popular roles

| Role | What you do |
|------|-------------|
| SOC analyst | Watch alerts and respond |
| Penetration tester | Attack with permission |
| Security engineer | Build safe systems |
| Cloud security | Protect cloud accounts |
| GRC analyst | Rules, risk and audits |
| Forensics | Investigate incidents |

## Certificates to consider

1. **CompTIA Security+**: the standard entry level.
2. **Google Cybersecurity Certificate**: very beginner friendly.
3. **eJPT / PNPT**: practical hacking starters.
