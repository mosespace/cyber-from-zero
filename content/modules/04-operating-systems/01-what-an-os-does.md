The **operating system (OS)** sits between the apps you use and the hardware. Examples: Windows, macOS, Linux, Android, iOS.

## Its main jobs

- Run programs and share the CPU between them.
- Manage memory so apps do not trample each other.
- Store files in folders.
- Control **who** (users) can do **what** (permissions).
- Talk to devices: printers, cameras, keyboards.
