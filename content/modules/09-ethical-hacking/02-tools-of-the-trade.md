Tools are just helpers. Understanding comes first. Use these **only on systems you own or have written permission to test**.

| Tool | Used for |
|------|----------|
| Nmap | Finding devices and open ports |
| Wireshark | Looking inside network packets |
| Burp Suite | Testing websites |
| Metasploit | Testing known weaknesses |
| John the Ripper / Hashcat | Testing password strength |
| Kali Linux | A Linux system packed with security tools |

## Set up a safe lab

1. Install VirtualBox or UTM (free).
2. Add Kali Linux as one virtual machine.
3. Add a deliberately weak target such as Metasploitable or OWASP Juice Shop.
4. Keep the lab network isolated from your real one.

## Rules of engagement

- Get **written permission**.
- Stay inside the agreed scope.
