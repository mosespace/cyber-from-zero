The best way to learn is by doing, and the best places are built for it.

## Where to practise

| Place                            | Style                               |
| -------------------------------- | ----------------------------------- |
| TryHackMe                        | Guided rooms, perfect for beginners |
| Hack The Box                     | Harder machines and challenges      |
| OverTheWire                      | Command-line games like Bandit      |
| picoCTF                          | Friendly competitions for students  |
| PortSwigger Web Security Academy | Free web security labs              |
| OWASP Juice Shop                 | A buggy shop you run yourself       |

## What is a CTF?

**Capture The Flag**: puzzles where you find a hidden text (the flag) by solving a security challenge.

## A 30-minute daily habit

1. 10 minutes reading a lesson.
2. 15 minutes in a lab.
3. 5 minutes writing what you learned.

## Remember

- Consistency beats long weekend sessions.
- Write notes. Teaching yourself on paper locks it in.
