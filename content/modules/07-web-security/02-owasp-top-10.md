**OWASP** is a non-profit group that publishes a famous list of the biggest web risks. Here are the ideas in plain words.

| Risk | Simple explanation |
|------|--------------------|
| Broken access control | A normal user can open admin pages |
| Cryptographic failures | Sensitive data sent or stored without protection |
| Injection | Attacker sneaks commands into a form |
| Insecure design | The idea itself was unsafe |
| Security misconfiguration | Default passwords, debug mode left on |
| Vulnerable components | Using old libraries with known bugs |
