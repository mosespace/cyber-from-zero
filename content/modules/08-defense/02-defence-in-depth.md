A castle has a moat, walls, guards and a locked inner room. If one fails, the others still protect the treasure. Security works the same way.


## Layers and examples

| Layer       | Examples                    |
| ----------- | --------------------------- |
| People      | Training, awareness         |
| Perimeter   | Firewalls                   |
| Network     | Segmentation, monitoring    |
| Host        | Updates, antivirus          |
| Application | Secure coding, input checks |
| Data        | Encryption, backups         |

## Zero trust

A modern idea: **never trust, always verify**. Even inside the network, every user and device must prove who they are each time.

## Remember

- No single tool is enough.
- Assume something will fail, and plan for it.
