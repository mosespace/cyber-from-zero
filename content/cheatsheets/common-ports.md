Print this and stick it near your desk.

## Web

| Port | Service | Notes |
|-----:|---------|-------|
| 80 | HTTP | Plain web pages |
| 443 | HTTPS | Encrypted web pages |
| 8080 | HTTP alternate | Often used for testing |

## Remote access

| Port | Service | Notes |
|-----:|---------|-------|
| 22 | SSH | Safe remote terminal |
| 23 | Telnet | Old and unsafe. Avoid |
| 3389 | RDP | Windows remote desktop |

## Email

| Port | Service | Notes |
|-----:|---------|-------|
| 25 | SMTP | Server to server mail |
| 587 | SMTP submission | Sending mail from a client |
